# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.3.x` | Yes |
| `< 0.3.0` | No (upgrade to `0.3.0`) |

## Reporting a Vulnerability or Numerical/Packaging Issue

If you discover a security vulnerability (for example, unsafe deserialization, dependency issues, or CI supply-chain risks) in `holom-core`:

1. **Do not open a public GitHub issue** for unpatched security vulnerabilities.
2. Send a private report to **dpabon180@unab.edu.co** with the subject `[SECURITY] holom-core: <short description>`, including steps to reproduce and affected versions.
3. For purely mathematical or physical bugs without security impact, please open a standard issue on [GitHub Issues](https://github.com/dudbilopr/holom-core/issues).

You will receive an initial acknowledgment within 5 business days.
